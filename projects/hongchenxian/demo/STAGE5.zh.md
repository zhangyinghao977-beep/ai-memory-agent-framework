# 阶段 5／DLC 04：从 Agent 迈向人工智能本体

[English](STAGE5.en.md) · [基础原型与前三个 DLC](DLC.zh.md)

**状态：理论设计，尚无模型级实现。** 这是红尘仙的 Agent 原型通向人工智能本体研究的第五阶段。DLC 04 是承载这次过渡的扩展；它和阶段 5 相连，但不改前三个 DLC 的分工，也不等同于商业 Agent 路线。

## 为什么继续往模型内部走

前四阶段已经能让 Agent 在模型外保留记忆原文，用 FSM 检索和执行，并让逻辑池沿各自的事件链工作。前三个 DLC 进一步给出短期工作副本、受控索引图，以及按具体或抽象索引复用过程片段的办法。这些能力让某些知识和过程可以追溯，但它们暂时还是外部架构。Transformer 的行为取决于参数、上下文与激活之间的组合；观察到一次输出或一次激活差异，并不等于已经找到可移植的逻辑。研究目标不是先完整反推现有模型，而是正向建立可登记、可翻译、可验证的结构。

## DNA 与蛋白质：两种软件表示

| 软件类比 | 对应 | 含义 |
| --- | --- | --- |
| **DNA** | **抽象映射关系** | 保存什么条件下可以从一种表示或状态走到另一种，和可复用关系的适用边界。记忆端可以登记有来源的不同实例，用它们辨认能共同复用的关系；关系不等于任意两条实例都能互换。 |
| **蛋白质** | **具体逻辑** | 当次把关系绑定到当前对象、条件、资源和证据后，形成的一条具体可执行路径。FSM 承接可执行步骤及回读；发出动作和确认结果不混同。 |

**翻译器**要把抽象关系实例化为当前可执行的逻辑，保留每次组合的来源和适用条件。具体经历可以作为新证据回到记忆，但执行结果不直接反写抽象关系。哪些经历足以修正映射、如何学习与翻译、哪些子路径可重用，仍须实验。这里的 DNA 和蛋白质只作软件类比，不是生物学机制，也不主张已有知识能从模型权重中无损抽出。

可以用事件链作最小载体：不是又做一个更大的工具层，而是尝试让模型内的表示包含可追溯的转换，并保留连接侧对上下文的适配能力。兼容的工程方向是把语义拆成可显式追踪的关系，再由连接侧参与组合；一处变化时，只重算受影响的部分，在无法判清影响范围时不假设局部更新足够。

## 第一项可证伪实验

1. 用前两种不同具体情境提供同一种可复用关系的带出处见证。
2. 在留出的第三种情境中，用抽象索引找出候选映射，并重新绑定对象。使用近义改写作正例，改变关键前提或交换角色作反例。
3. 比较整段重算与局部更新：记录输出是否一致、无关链是否保持、哪些节点确实重算、条件不满足时是否拒绝。若关系不能跨情境转用，或者局部更新破坏了其他语义，则这轮没有通过。

前三个 DLC 已有独立合成原型。上述学习、翻译和局部重算仍是设计与待验证假设，没有作为模型能力发布。
