# 红尘仙：基础原型和前三个 DLC

[English](DLC.en.md) · [基础版与架构图](README.md) · [阶段 5／DLC 04：从 Agent 走向人工智能本体](STAGE5.zh.md)

这里是独立个体 Agent 的四阶段简易原型。前三个 DLC 共用这个基础版，可以各自运行和验证；它们还不是一个已经集成部署的系统。

在本目录运行 `python demo.py`，需要 Python 3.10+，只用标准库。不用模型、API key、私有录像或网络服务。

| 扩展 | 设计与可复现行为 | 从本目录运行 |
| --- | --- | --- |
| **01 · 可局部重建的知识库与补丁** | 长期原文保留。按需重建片段形成隔离的短期工作副本，先在副本上改。显式合并时对照分出时的版本，冲突保留，不覆盖原文。 | `python dlc01/short_memory.py` |
| **02 · 索引图** | 索引以图连接关键词与可访问片段，且各角色只看自己的地图。商业 Agent 不直接进入唯一可信源或知识树；演示网关仅读取授权的派生视图，撤回后原入口失效。 | `python dlc02/index_map.py` |
| **03 · 事件链、FSM 协议和神经反射** | 具体索引定位已拆解过程的确定版本和片段；抽象索引归组可复用候选。反射挂载后从同一 FSM 协议进入，按本轮条件核对并等新证据回读。 | `python dlc03/protocol.py` |

其他入口：`python dlc01/rebuild.py --query 周四`。如需复跑测试，到各自目录执行 `python -m unittest -v`；基础版在本目录执行同一命令。

**证据边界。** 使用合成材料、脚本分工和模拟执行器。DLC 02 的按词索引用 SQLite 索引键寻址，未证明比倒排索引更快；网关信任调用端之外的身份绑定和文件隔离，不是商业级鉴权系统，撤销不可能收回此前已被读走的数据。DLC 03 的挂载及正在执行的状态目前只在进程内演示。DLC 04 与阶段 5 是下一步研究设计，不属于本次可运行交付。
