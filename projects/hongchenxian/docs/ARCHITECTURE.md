## 当前设计：主动搜索与二期局部注意力

2026-11-07 的当前选择是**先走主动记忆搜索**：逻辑从索引字典主动寻找第一个入口，必要时沿多层索引继续查找，读取各索引角度的简介，再决定是否展开正文。索引本身也可以被索引；时间、地点、人物、工具、对象、结果只是一个经历的入口示例，不是所有记忆都被强制套用的六字段格式。

**局部注意力属于二期设计，现在一起写入文档。** 目标原文应与相关上下索引的简介及可展开引用一起提供。上下索引可以包含层级和关联，不等于固定前后两段；简介跟着索引走，同一正文可以从不同入口得到不同简介。原文保留，不因简介、整合或读取预算而压缩、覆盖或删除。逻辑作最终判断，FSM 与记忆负责状态和材料支持，不借供给材料接管判断。

工具结果先记入缓存并保留原始发生记录；“结果确实返回过”与“结果内容为真”分开。休息时由同一 FSM 的另一部分组织缓存经历整合。此处的整合不同于把子链接入当前分析范围的结构合并，限定词只是消歧说明，不是另造新算子。整合时机、准入依据和完整协议仍待落实，不能声称现有离线协作链已经实现自主整合。

**历史变更：** 早先的“优先被动供给”计划由本次“现阶段先主动”取代。被动指无需逻辑先发出检索请求，外部先提供材料；这个含义和历史计划保留，后续是否、何时及怎样配合主动仍未定，本次没有永久废除被动。

[双语流程图及设计／实现对照](../../../docs/ARCHITECTURE_FLOWS.md)与[当前词典](../../../docs/GLOSSARY.md)给出同一口径。完整经验派的检验对象始终是逻辑、记忆与 FSM 的整体；这里的 agent 切片和离线协议检查不能代替完全体的验证。

**跨项目命名边界：** 经验主义的 PA 已更名为 CA（Chain Attention），使用寻址为 CA → EA → KA，见[对应设计图](../../../docs/ARCHITECTURE_FLOWS.md#use-addressing)。这不把红尘仙的 dictionary／preview／readOriginal 接口逐一等同于 CA／EA／KA，也不表示黑盒模型的内部训练已按此实现。

## 数据与执行链

合成 claim 绑定成员、session、policy 和 ticket。记忆引用只携带固定 snapshot/pin；工具先查索引，再预览，最后读取选择的原文。原生工具的来源记录与结果必须匹配，工具返回不自动成为成员的最终意见或生命周期决定。

`runCentralPlugin` 在本地 double 注册 provider 与 stream hook。每步先准入，随后保护层核对实际序列化请求，先记录 spend 再交给注入的离线 forward。最终 completed source、Body acceptance、receipt、settlement 和意见 staging 是不同记录。

重开先核验保存的来源与账本。只有完整一致的已完成来源才补齐同一票据的缺失本地记录；未知、冲突、异源或缺少完成证明的状态保持挂起。不能把后来的决定倒写成旧请求的成功，也不凭异常就再次调用 provider。

## 重要边界

- `sdk-runtime-double.mjs` 是可控模型，不是已安装的官方 runtime。
- 测试包含十个合成身份，但实际执行链只覆盖一个成员，不证明十成员并行或集体会议。
- 来源哈希与 lineage 检查不等于密码学身份认证或主机写入者排他控制。
- 临时 SQLite 持久化与模拟 session reopen 不等于跨进程、断电或真实服务器恢复。
- 读取预算与窗口限制不能被表述为删除历史或自动遗忘的许可。
- 官方加载函数在本副本无条件拒绝；生产接线、原身份迁移与 72 小时运行均在范围外。

`syntheticOnly` 与 `officialRuntimeExecuted` 是当前固定离线组成的报告标签，不能认证任意调用方注入的 SDK/deps。直接复用模块时须另行约束依赖、权限和网络。
