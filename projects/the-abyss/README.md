# 深渊 / The Abyss

[中文](README.md) | [English](README.en.md)

**名词解释：** [完整术语汇编与事件链专节](../../docs/GLOSSARY.md)。这是最新讨论快照，保留历史定义和实验边界。

[新证据与粒度小试（2026-11-07）](evidence/2026-11-07/README.md)：历史训练摘要、正在进行的阶段，以及仅完成 2/10 种子的 G1 新试验，分别记录。

1. **逻辑是知识的可达路径。**
   Logic is the path that makes knowledge reachable.

以上是本项目指定的理论主张，不是已实证结论，也不在此推导额外定理。

深渊是一套面向**记忆与学习的半成品人工智能方案**。它研究如何保留经验、形成有来源的记忆与可复用知识，在任务中展开知识，并依据新经验局部修订。基础 LLM 本身不提供这里设计的持久状态和完整学习机制；现有实现也尚未完成整套方案。

本目录保留去标识的理论摘编，并新增 [implementation](implementation/README.md) 中选取的原研究代码及适配副本：65 个核心 Python 文件、25 个 `test_*.py` 文件、31 个实验 Python 文件（含共用辅助文件）、11 份计划。它提供基础记忆层、知识包、事件链 AST 和 T1–T10 合成实验入口；不代表整个原工作区已发行。

经验主义事件链表达对象、关系、条件与流转；红尘仙工作事件链记录工作调用、依赖、回执与恢复。二者有工作过程映射，但不能把协作账本的运行当作知识学习算法已经实现。T4 的人工 FSM 只借用存活与恢复思路。
