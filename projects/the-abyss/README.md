以上是本项目指定的理论主张，不是已实证结论，也不在此推导额外定理。

本目录是“深渊”经验主义人工智能方案的去标识技术摘编，用于与红尘仙研究预览一起阅读。它不是经验主义项目的源码发行、当前工程规范或训练成果发布。整理日期为 2026-11-06。

经验主义方案关注经验如何被组织成可复用知识、如何在具体任务中展开，以及如何依据新经验修订。红尘仙关注黑盒 Agent 的工作协作。二者有明确的工作过程映射，但不能把协作账本的运行当作知识学习算法已经实现。
