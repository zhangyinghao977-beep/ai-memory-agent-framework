# 深渊 / The Abyss

[中文](README.md) | [English](README.en.md)

1. Logic is the reachable path through knowledge.

This is the project's stated theoretical proposition, not an empirically established conclusion. No additional theorem is inferred from it here.

This directory is a de-identified technical digest of The Abyss, the empiricist artificial intelligence proposal, intended to accompany the Hongchenxian research preview. It is not a source-code release of the empiricist project, its current engineering specification, or a release of training results. Compilation date: 2026-11-06.

The empiricist proposal concerns how experience is organized into reusable knowledge, unfolded for concrete tasks, and revised in light of new experience. Hongchenxian concerns collaboration among black-box Agents. There is an explicit mapping between their work processes, but running a collaboration ledger cannot be treated as implementation of knowledge-learning algorithms.

## Included and excluded material

The included material is a newly written technical summary based on existing design documents, not a complete copy of original conversations or source documents. Explicit corrections in later versions take precedence over earlier shorthand; unresolved mechanisms remain unresolved.

Private quotations and conversation transcripts, personal identities and accounts, message identifiers, private addresses, absolute paths on personal computers, raw training data, weights, and secret values are excluded. This directory contains no copied third-party code and introduces no project license or authorization on behalf of the original project.

This is currently a de-identified theoretical compilation. The latest local source and experiment inventory has been confirmed, and an isolated candidate is under review. This directory currently provides theoretical documents; the complete source has not yet been merged into it or independently reproduced. This does not mean that the original project never had local code or experiments. Hongchenxian code cannot substitute for the empiricist implementation.
