# 深渊 / The Abyss

- **逻辑是知识的可达路径。**
  Logic is the path that makes knowledge reachable.

[English](README.en.md) · [复现说明](docs/REPRODUCIBILITY.zh.md)

深渊是一套面向记忆、知识组织与局部学习的人工智能研究方案。本候选包含它的部分代码和受控实验：把经历留下来，区分经历与形成后的记忆，登记有版本的知识包，再研究如何沿事件链调用和修正局部计算单元。

**当前是研究预览，整体方案尚未完整实现。** 它不是现成的通用智能体，也不是已经验证能为任意 LLM 提供持续学习的插件。代码、实验观察和架构设想分别说明，方便检查每项主张的依据。

这是独立整理的源码研究预览。**安装、测试和训练流程尚未由本副本执行验证**；本次只做静态检查，见 [STATIC_CHECKS.json](STATIC_CHECKS.json)。代码的公开许可仍待权利人确定，见[许可状态](LICENSE-STATUS.md)；公开可读不等于已授予开源使用许可。

| 层次 | 本预览包含什么 | 能据此说明什么 |
|---|---|---|
| 已有代码 | SQLite 经验与记忆层、来源与版本记录、知识包登记、事件链 AST、工作缓存与边界检查、局部修正记录 | 对应的数据结构和接口已写出；是否通过当前环境的检查，应看新的测试记录 |
| 受控合成实验 | T1–T10 的任务生成、KA/EA/CA 局部计算、分层训练、修复、固定 FSM 存活实验及晶格对照 | 在指定出题器、种子、预算和人工结构下的观察；不自动推广到自然语言或真实开放环境 |
| 工作假设 | 从经验形成更完整的知识结构、扩大泛化范围、长期持续学习与更完整的主体延续 | 研究方向；已有局部结果尚未证实完整方案 |

KA、EA、CA 在这些实验中分别承担包内计算、链内事件选择和链间选择等局部职责。它们是这里具体实现的实验单元，不代表所有注意力机制都具有同样含义。

这里有两种需要分清的事件链。**经验主义事件链**是对象、关系、条件与流转的表示，参与学习和推理。**红尘仙工作事件链**记录工具调用、执行回执、产物与恢复过程。二者不能互换；T4 只是借用了存活和恢复的思路，其 FSM 由人工编写，不能据此声称实现了红尘仙或自主编程系统。

历史实验已经超过早期“尚未训练”的阶段。其中 T10 的历史记录为 **50/50 个任务完成**，但这不是所有预测都成立：**S2 未通过，新包泛化问题仍然存在**。T8/T9/T10 的向量或关系表由合成事件链生成，生成公式、比较器和窗口等结构仍有人工设计。历史摘要与新副本的复现记录必须分开；本次发布整理没有运行训练或 pytest，也没有独立复现这些成绩。
