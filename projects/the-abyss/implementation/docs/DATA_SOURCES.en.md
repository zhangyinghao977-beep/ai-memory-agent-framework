# Data sources and reproduction limits

This preview does not distribute corpora, tokenizers, pretrained weights, databases, token shards, or original run receipts. T1–T10 are controlled synthetic experiments whose data are generated by code. They do not require the 119M backbone or the external materials below. See [RESULTS.en.md](../historical/RESULTS.en.md) for historical results.

These materials belong to an optional natural-language integration path. Public source information does not mean that the complete historical pipeline is reproducible from public inputs. No downloads, weight loading, or experiment reruns were performed while preparing this documentation.

## Verification status

- **Officially checked during this review:** the project review checked official sources for TinyStories' CDLA-Sharing-1.0; the distinction between the pinned Wikipedia data card's CC BY-SA 3.0/GFDL and current Wikimedia 4.0/GFDL terms; EmpatheticDialogues' CC BY-NC 4.0; and NRC EmoLex's prohibition on redistribution.
- **Local records:** all other license descriptions, historical byte counts, SHA256 values, and processing details come from existing source inventories. They were not individually rechecked against live official pages or new downloads. A checksum identifies historical bytes; it does not guarantee that a current URL still supplies them.
- Data, weights, tokenizers, and software have separate provenance and licenses. The project's code license does not automatically cover external materials.

The pinned card states CC BY-SA 3.0/GFDL, with some text available only under CC; [current Wikimedia terms](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use) use CC BY-SA 4.0/GFDL. Preserve this version distinction, article URLs, titles, and attribution sources. Do not relabel the historical snapshot as a whole or substitute the cleaning code's license for the text license.

Historical processing grouped text after NFC normalization, whitespace collapsing, and trimming, then used the fixed salt `empiricist-expansion-v1` for approximately 98%/1%/1% train/validation/test splits. Only the first document in each group in fixed file/row order was retained. The recorded deduplicated total is 1,847,940 articles; this is not a comprehensive quality or privacy audit. Near duplicates, semantic paraphrases, cross-language counterparts, and contamination with prior training corpora were not comprehensively checked.

**Missing reproduction step:** the large-corpus `prepare_scale.py` depends on an existing `corpus_index.sqlite`. This review did not find a complete program that rebuilds that index from downloaded Parquet files. The existing `读取示例.py` only reads an existing index. Raw-file acquisition and checksum verification are independently possible, but the 1B-token plan, historical local splits, and full pipeline are not yet established as reproducible. Upstream filenames containing `train` do not authorize using every row for this project's training; the local evaluation isolation must be rebuilt and checked.

## The 16,384-token vocabulary

The integration path refers to the historical filename `tokenizer_fixed_16384.json`. Original preparation records describe ByteLevel BPE with a vocabulary of 16,384, `min_frequency=2`, pad/eos/unk special tokens, and 20M characters from the training portion of each of the following sources. These identify inputs, not a public tokenizer download.

The [official TinyStories data card](https://huggingface.co/datasets/roneneldan/TinyStories) lists CDLA-Sharing-1.0. Availability of that historical SimpleWiki file remains unverified; no direct file URL has been guessed here. Check text licensing and attribution for the selected dump.

The target tokenizer SHA256 is `3cc4001a8a9418e1f1a97c47b809fbd85860ccb0c44b6d6dc4a0326e791ac7fe`. Original `scripts/prepare_data.py` and `src/data.py` contain preparation logic, but an isolated rebuild has not been verified in this preview. Character sampling order, cleaning/splitting, exact special-token strings and order, and dependency versions must match the original records. The source table and BPE settings alone do not guarantee identical bytes. A different checksum must not be presented as the original tokenizer.

## Optional 119M backbone

Historical integration comments identify another research branch's `hardened_empiricist_model_119m_billion_seek_common_final.pt`, reportedly saved by `run_streaming_billion_scale_seek_common_reserve_diff.py` on 2026-10-21. `backbone.py` explicitly describes a reimplementation of the backbone path from `hardened_empiricist_kernel.py`; it should retain that provenance rather than being described as wholly independent original work.

This review did not find a public weight URL, public model card, release license, or complete public retraining procedure. The exact source-kernel version, its license, and checkpoint identity remain to be supplied. The output-equivalence test skips when the original kernel is absent; a skip is not a passed comparison. Running a network of the same shape with random weights does not reproduce the pretrained checkpoint. The T1–T10 synthetic experiments do not depend on this integration path.
