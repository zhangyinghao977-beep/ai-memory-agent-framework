## 任务、分组与保持不变的条件

每个种子生成一次 96 个原子对象（12 个参考家族，每家族 8 个成员）、2,048 个无序对象对及各对的两个世界题目。原子身份、历史、查询、赢家、标签及原划分保持不变；评估只用原 `test`，每种子含 512 个无序对、1,024 个世界题目。两个世界复用同一个对象对，不能当成独立重复。

学习器分配 96 个标量槽，分数为 `world_sign * (w[group(A)] - w[group(B)])`。从可见历史与查询解析 A/B、以及世界反转，都是程序提供的规则。两档训练池是嵌套选择的 64/512 对，每对取一个世界实例；每臂零初始化，4,096 次呈现，学习率 0.05，无正则化。数据、标签及呈现顺序在同种子、同监督档的各臂间一致；同槽比较不更新权重，但仍消耗呈现预算。

- `atomic`：每原子独立一槽。
- `family2/4/8`：在生成器给定的参考家族内随机、嵌套地合并，不读取隐藏数值来选组。
- `random2/4/8`：在全体原子间随机、嵌套地合并，组大小和组数与对应 family 臂一致。

变化的是原子到共享分数槽的映射。家族是给定先验，不是模型发现的知识；分配槽数虽固定，有效独立分数随组大小从 96 降到 `96 / 组大小`，不声称有效容量或 FLOP 相同。目标始终是原子赢家，同槽平局计 0.5。512 对是所选训练池大小；有限次随机呈现中，四个种子实际呈现 511 个不同对，其余六个呈现 512 个，不把未呈现项计入已见图。

## 包内细节与比较图

共享的总体收益伴随原子区分损失。family8 的包内准确率恒为 **50%**，由同家族所有原子共享一个分数、平局计半分直接决定，是构造结果而非学得的能力。64 对时，atomic 包内／跨包均值为 **57.32%／70.50%**，family8 为 **50.00%／84.97%**；512 对时分别为 **71.30%／87.83%** 与 **50.00%／87.88%**。各种子的原包内测试只有 21–46 个无序对，跨包题占多数；总准确率不能替代包内区分评价。

64 对时实际见到 64–77 个原子，仍有 19–32 个未见原子，原子比较图有 32–36 个连通分量。512 对时十个种子均见到全部 96 个原子，比较图连通。共享可能将已有家族先验传给未见成员或连接断开的比较分量；本实验没有单独隔离这些中介机制。共享槽碰撞与原参考家族内／跨家族不是同一个划分，跨槽也可能出现不同原子对要求相反赢家的冲突。

汇总中的事后 lookup 参照使用测试标签，按每个无序组对选多数赢家，同槽计半分；它只用于诊断合并后的冲突，不参与训练或选臂。它比共享标量排序模型更宽松，不能把该参照或“已知正确组再随机解同槽”的参照宣传为任意模型的信息论上界。
