## 两个入口

### [深渊 / The Abyss](projects/the-abyss/README.md)

1. **逻辑是知识的可达路径**

这是本项目的理论主张，不是已由实验证明的结论。该项目讨论经验如何形成可复用知识、知识如何组合和展开、以及如何依据新经验修订。入口提供中英文设计、来源和证据说明。

本地最新源码与合成实验清单已经确认，隔离候选仍在整理审查。本目录暂提供理论文档，不能据此声称完整源码已经合并、独立复现或通过全部实验。实验回执齐备与实验达到预期是不同状态。

### [红尘仙 / Hongchenxian](projects/hongchenxian/README.md)

黑盒 Agent 的工作协作研究：持续身份、段落索引记忆、固定共享快照、逐步调用账本、生命周期决定及来源核验恢复。本候选包含一条可离线运行的 synthetic 工程链，只有 Node 内置依赖。

红尘仙的工作事件链承接工作记录、调用、依赖、挂起和接续。它不等于深渊的知识组合学习、广义 AST、内部九算子或独立学习事件链已经实现。

## 运行与证据

以下命令仅运行红尘仙离线测试，不训练深渊模型：

```sh
node --version  # 已验证 Node.js 24.22.1
npm test
```

无需 npm install、Python、官方模型 SDK 或 API key。测试在临时目录创建合成数据，默认防误调用保护拒绝常见 Node 网络入口；它不是恶意代码沙箱。不要传入真实数据路径或凭据。

本检查点的红尘仙离线测试已重新运行，72/72通过。范围见 `evidence/VALIDATION.json`；这不包含深渊最新源码的复验。完整性清单仅覆盖本检查点，后续源码接入或文件变更必须重新扫描、验证并更新清单。

## 仓库分区

- `projects/the-abyss/`：深渊中英双语方案与证据边界，预留经审查的最新实现接入。
- `projects/hongchenxian/`：红尘仙源码、synthetic tests 与中英双语说明。
- `scripts/`：离线防误调用、候选扫描、完整性验证。
- `evidence/`：来源清单和范围明确的验证记录。
- `docs/`：两项目共享的排除范围与发布清单。
- `third_party/`：独立的上游许可文本；不替本项目选择许可证。

理论、实现、运行、验收和未达预期结果分开记载。没有完成真实十成员恢复、72小时连续运行、一般学习能力、复杂度突破或意识的声明。
