# 候选范围与扫描边界

[English](EXCLUSIONS.en.md)

红尘仙部分从一个已封存候选中选取 32 个 `.mjs` 文件，并添加本预览的说明和验证脚本。深渊部分保留 4 组中英双语技术摘编，现已在 [implementation](../projects/the-abyss/implementation/) 中选入本地研究源码：65 个核心 `.py`、25 个 `test_*.py`、31 个实验 `.py`（含辅助脚本）及 11 份用于新运行的计划配置。没有把原工作目录整体复制进来。

选入源码的来源相对路径与读取时哈希见 [SOURCE_SNAPSHOT.json](../projects/the-abyss/implementation/historical/SOURCE_SNAPSHOT.json)。候选副本包含另行记录的可移植性修改；新计划配置不是历史冻结记录，历史结果摘要不是原始回执或独立复现。原研究工作树及运行中实验未被本次整理修改，详见[来源与证据说明](../projects/the-abyss/implementation/NOTICES.md)。

排除：红尘仙原环境的官方插件/启动器及原 Python runner、原始公共源码摘录、服务器配置和读出、历史传输脚本/tar/b64、账号目录、真实数据库/WAL/SHM、真实成员记忆、原始模型回复、邮件/聊天室、个人资料和私有链接。完整私聊式术语表、私人协作记录与带私人路径的历史原稿也不纳入。

深渊另排除外部材料适配模块、已停用的 toy 实验、第三方语料/词表/分词器文件、token 分片、预训练权重、运行数据库及原始运行回执。T1–T10 的输入由合成出题代码生成，不需要这些外部材料。第三方材料仅保留来源与获取说明；119M 底座的公开获取、来源版本与许可，以及从 Parquet 重建 `corpus_index.sqlite` 的完整流程仍未补齐，见[数据来源](../projects/the-abyss/implementation/docs/DATA_SOURCES.zh.md)。项目代码的[公开许可尚未确定](../projects/the-abyss/implementation/LICENSE-STATUS.md)。

候选扫描检查秘密常见格式、私人路径、账号/主机标识、电子邮箱、IP、敏感文件扩展名、符号链接和静态 import 闭包。只输出位置与类别，不输出命中值。固定 synthetic header 用例有精确审阅的假值例外；未知值仍报错。

扫描结论以对应脚本的覆盖范围和实际报告为准。扫描是启发式检查，不能证明不存在任何秘密或第三方权利问题。哈希只用于核对清单中的文件字节，不保证代码安全性、作者权利或历史实验所用版本。扫描不读取父目录、原始凭据目录或真实数据。

本次深渊源码整理未执行依赖安装、pytest、训练或下载；已有历史结果不能充当新副本的验证结果。后续新增或修改文件需重新进行适合其范围的扫描与验证，并更新清单。
