# 候选范围与扫描边界

[English](EXCLUSIONS.en.md)

只从一个已封存候选中选取 32 个 `.mjs` 文件，并添加本预览的说明和验证脚本。经验主义部分另有4组中英双语技术摘编，完整私聊式术语表与带私人路径的历史原稿不纳入。没有把工作目录整体复制进来。

排除：官方插件/启动器与 Python runner、全部原始公共源码摘录、服务器配置和读出、历史传输脚本/tar/b64、账号目录、真实数据库/WAL/SHM、真实成员记忆、原始模型回复、邮件/聊天室、个人资料和私有链接。

候选扫描检查秘密常见格式、私人路径、账号/主机标识、电子邮箱、IP、敏感文件扩展名、符号链接和静态 import 闭包。只输出位置与类别，不输出命中值。固定 synthetic header 用例有精确审阅的假值例外；未知值仍报错。

扫描是启发式检查，不能证明不存在任何秘密或第三方权利问题。哈希保证本次清单字节一致，不保证代码安全性。扫描不读取父目录、原始凭据目录或真实数据。任何后续新增文件都必须重新扫描、测试并更新清单。
