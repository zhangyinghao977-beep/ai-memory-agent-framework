## 必须由所有者决定或另行核验

1. 本次预览仅纳入已核验的红尘仙离线源码与深渊理论摘要；深渊本地最新源码的审查和并入另行进行。

3. 是否接受只发代码与汇总证据；若扩展真实实验资料公开范围，单独审查隐私和授权。
4. 上游公开许可证检查基于当前 master；精确源码历史提交未由该页面确定。不要将 master 作为安装 rc.5 一致性证明。
5. 如果准备 npm、CI 或真实 SDK 发布，需要新的依赖/执行范围审查。本副本没有自动发布配置。
