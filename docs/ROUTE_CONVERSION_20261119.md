# 路线决策：从经验学习三疑问面之间的转换

登记日期：2026-11-19。状态：作者确认的研究方向与待检验假设，不是实现完成声明。

## 本次决定

停止把逆向拆解 Transformer 黑箱、解析完整“多项式函数”作为主路线或新架构的前置条件。“多项式”在这里沿用项目的讨论表达，不据此断言实际 Transformer 是某个已知有限多项式。

已有逐层观察、扰动和输出核算保留为诊断记录，不删除、不改写历史结果，也不因路线改变而宣布它们无价值。接下来的重心转向：连接主义侧如何从经验学到可复用的转换，并在具体上下文中组合和表达这些转换。

## 概念边界

本项目将事件链的最小节点理解为三疑问面（What／How／Why）之间的一次转换。此处登记的是研究对象，不把任意一句自然语言、固定八槽模板、一个 API 调用或预制技能直接认定为该节点的实现。转换的条件、输入输出、方向、组合与修订方式，仍需通过经验和检验具体化。

DNA／蛋白质／翻译器只作软件类比：持久记录与运行时表达可以不同，但必须能追溯。这里没有提出新的生物学机制，也没有借类比另起一套记忆库、FSM、技能或图结构骨架。

- FSM 继续承担运行与动作底层的固定流程；语义判断和抽象学习不能仅靠给 FSM 新命名而自动获得。
- 记忆保存原始经验与证据；抽象转换需要保留形成来源和适用条件，不能拿摘要覆盖原文。
- 技能可以是表达或执行形式，不替代知识形成、事件链与上下文组合机制。
- 继续沿用既有[事件链与关系定义](EVENT_CHAIN_RELATIONS.md)，本次不是将学习事件链与工作事件链拆成互不相关的系统。

## 证据与假设分开

本次阅读的 Probe 15 报告比较了五道嵌套关系题的输入格式：原文与短事件表达均为 4/5，方括号 Codon 为 3/5；平均候选边际分别为 2.578、2.687、1.315。这个小样本支持继续比较表达方式，但不证明短事件链是唯一或普遍最优格式。

上述数字来自报告呈现，本次没有独立复现其原始代码和回执。格式比较、候选排序、完整自由生成、转换学习和架构实现是不同证据层级，不能互相替代。原始报告、运行日志、权重、私人对话和本地激活不随本文发布。

## 下一步研究问题

1. 从具体经验出发，连接主义侧究竟学习什么可复用的转换，而非由研究者预先手写全部答案？
2. 同一转换怎样在不同对象和上下文中复用，又如何保留条件、方向与来源？
3. 多个转换如何组合并表达为当前情境需要的事件链，失败后怎样依据新经验修订？
4. 怎样区分已学转换、表面格式适配、现有模型知识和人工预置规则带来的收益？

这些是下一阶段的研究方向，不是已发布训练流程、自动抽象算法或完成的实验验收。学习机制、接口和评价仍待具体设计与验证。

## 本次发布范围

只增补路线说明与入口，不修改算法、不新增骨架、不发布本地实验文件。已有源码、历史证据与冻结结果维持原样。本次文档决策优先于将黑箱完全拆解视为必要前提的旧研究设想，但不追溯改变旧记录。
